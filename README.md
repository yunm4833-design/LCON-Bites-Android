# LCON BITES

An offline-first Android food guide for the Leeds Conservatoire area.

## Build

Pushes to `main` trigger the GitHub Actions Android APK workflow.

## Offline data

The app stores places, favourites and ratings locally. The initial release includes a small bundled sample dataset; an offline basemap package will be added separately once its source, licence and size are verified. No online tile service is used by the app.

OpenStreetMap contributors data attribution will be displayed in-app when an OSM-derived basemap is integrated.
